## Различные реализации взаимодействия горутин через каналы



### 1. «Пинг-Понг» (Базовая синхронизация)

Цель: Понять, как работает блокировка при передаче данных в небуферизированный канал.
Задание:
* Создайте строковый канал.
* Запустите две горутны.
* Первая горутина отправляет в канал сообщение "ping".
* Вторая горутина читает из канала, печатает сообщение и отправляет обратно "pong".
* Первая горутина читает ответ и печатает его.
* Cделать чтобы горутины работали в бесконечном цикле, и остановите их через отдельный канал
