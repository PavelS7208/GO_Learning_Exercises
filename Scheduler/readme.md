# Упрощенный Планировщик задач с горизонтальным масштабированием (шардированием) с динамическим изменением приоритета


## Общее описание

Многошардовый пул для управления задачами с приоритетами. Задачи распределяются по шардам, каждый шард хранит очередь задач в бинарной куче. Планировщик поддерживает динамическое добавление и удаление шардов с автоматической перебалансировкой.

---

## Структура данных: MaxHeap

Бинарная куча с максимумом на вершине. Контракт для хранимых элементов — два метода: `Key()` (уникальный идентификатор) и `Order()` (значение приоритета).

Особенности реализации:

- Дополнительный индекс `map[Key → index]` для O(1) поиска элемента по ключу
- `Push` — вставка 
- `Pop` — извлечение максимума с 

## Планировщик (Pool Шард-ов)

Динамический пул шардов ([]*shardEntry). Каждый шард — это нода + уникальный ShardID + флаг состояния ребалансировки.
Синхронизация: sync.RWMutex — запись (Lock) при добавлении/удалении шардов, чтение (RLock) при работе с задачами.
Добавление задач

* AddTask — round-robin по шардам
* AddTaskToShard — добавление в конкретный шард по ID

Получение задач

GetTaskFromShard — извлекает задачу с наивысшим приоритетом из указанного шарда. Если шард опустел — асинхронно запускает ребалансировку (через CompareAndSwap на флаге, чтобы не запустить несколько горутин одновременно)

Изменение приоритета

ChangeTaskPriority — поиск задачи по всем шардам, обновление приоритета
ChangeTaskPriorityInShard — то же, но в конкретном шарде

* AddShard — добавляет шард и асинхронно запускает ребалансировку (stealing с самого загруженного шарда)
* RemoveShard — удаляет первый пустой шард; возвращает false, если пустых нет или остался один
* ForceRemoveShard — принудительное удаление шарда с заданным ID; задачи раскидываются round-robin по оставшимся шардам перед удалением

Минимальное количество шардов в пуле — 1.\
Ребалансировка (work stealing)\
Алгоритм: найти самый загруженный шард (по атомарному счётчику), украсть у него половину низкоприоритетных задач (PopNLowest(len/2)), передать их целевому шарду.
Запускается в фоновой горутине в двух случаях: шард опустел при вызове GetTaskFromShard, или был добавлен новый шард через AddShard.



## Задача (Task)

Единица работы с двумя полями: `TaskID` (уникальный int-идентификатор) и `Priority` (int в диапазоне 0–100).

Предустановленные уровни: `Low=0`, `Normal=25`, `High=50`, `Critical=75`, `Urgent=100`.

Реализует интерфейс `heap.Item` через методы `Key()` и `Order()`.
