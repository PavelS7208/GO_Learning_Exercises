## Дефрагментатор аллоцированной памяти

За основу взято домашнее задание с курса продвинутый GO. Немного расширил ТЗ к заданию.

Дан участок памяти и список указателей которые указывают на начало выделенных блоков памяти. Перед каждым выделенным блоком есть заголовок равный 1 байту в нем хранится размер этого блока. Предполагается что в процессе работы часть блоков уже освободилось и в памяти образовались "дырки".
Задача: Реализовать функцию дефрагментатор, которая оптимизирует аллоцирование heap путем переноса блоков переменной длины на свободные участки, с целью ликвидации "дырок"



```go
      memory := []byte{
            5, 1, 2, 3, 4, 5, // блок 0 длиной 5
            0, 0, 0, 0, 0,   // дырка
            4, 6, 7, 8, 9, // блок 1 длиной 4
            0, 0, 0, 0, 0, 0,  // дырка
            6, 11, 12, 13, 14, 15, 16, // блок 2 длиной 6
      }
      pointers := []unsafe.Pointer{
            ptrAt(memory, 1),  // блок 0
            ptrAt(memory, 23), // блок 2
            ptrAt(memory, 12), // блок 1
      }
	  
      Defragment(memory, pointers)
```
